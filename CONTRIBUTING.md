# Contributing

See [local development](docs/development.md) for setup and checks and [AGENTS.md](AGENTS.md) for repository conventions. Track feature proposals and delivery status in [plan.md](plan.md). Each item should state the outcome, acceptance criteria, dependencies, and verification.

When submitting a lesson fix, include the lesson ID, the starting files, the command you tried, and the observed and expected results. When changing a rubric, include the starter, partial, and passing scores you verified. Follow the [lab authoring guide](docs/lab-authoring.md) and update the companion experience through the shared course files.

Learner installation lives in [docs/install.md](docs/install.md). The site and Linux archive use that file, so update it when a supported install path or command changes.
